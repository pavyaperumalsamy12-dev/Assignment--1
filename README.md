# Assignment--1
Effect Size and Statistical Power

Overview

This project explains Effect Size and Statistical Power using Python. It demonstrates how to measure the difference between two groups and calculate the required sample size for statistical analysis.

Topics Covered

- Effect Size
- Cohen's d – Standardized Mean Difference
- Pearson's Correlation Coefficient
- Statistical Power
- Type I and Type II Errors
- Power Analysis
- Minimum Sample Size Calculation
- Statistical Power Curve
- ML/AI Applications

Technologies Used

- Python
- NumPy
- Matplotlib
- SciPy
- Statsmodels

Implementation

The notebook uses two groups:

- Control Group
- Treatment Group

It calculates:

- Control Mean
- Treatment Mean
- Mean Difference
- Pooled Standard Deviation
- Cohen's d
- Required Sample Size
- Statistical Power

It also generates a Power vs Sample Size graph for small, medium, and large effect sizes.

Installation

Install the required libraries:

pip install numpy matplotlib scipy statsmodels

How to Run

1. Download the ".ipynb" file.
2. Open it using Jupyter Notebook or Google Colab.
3. Run the cells one by one.
4. View the calculated results and graphs.

ML/AI Connection

Power analysis helps determine the required test-set size for ML experiments. Cohen's d helps compare model performance and understand effect sizes.
